# Данные в AnyPatcher 0.2

Файлы, исходные копии, изменения и журнал проекта хранятся на вашем компьютере. Для обычного анализа и редактирования приложение не отправляет их разработчику и не требует аккаунта AnyPatcher. В версии 0.2 нет встроенной аналитики использования или автоматической отправки crash-отчётов.

Локальный помощник обращается к Ollama на этом компьютере. Для этого модель должна быть заранее загружена. Скачивание Ollama, моделей, внешних анализаторов и обновлений выполняется отдельно.

При включении облачного ИИ приложение передаёт выбранному провайдеру текст задания и фрагменты активного проекта, которые помощник читает через ограниченные инструменты. Для каждого облачного запуска требуется согласие. Полный архив автоматически не загружается. Автоматическое скрытие распространённых секретов не заменяет вашу проверку содержимого.

API-ключи хранятся в macOS Keychain или Windows Credential Manager. Они не включаются в рецепты, проекты и экспорт контекста. Проверенные способы декодирования сохраняются в метаданных проекта для конкретного файла и ID объекта. Ключи и IV находятся в macOS Keychain или Windows Credential Manager; в память окна они передаются только для чтения/редактирования ресурса. Экспортируемые архивы и рецепты патчей не содержат эти ключи. При исследовании загрузчика с облачным ИИ найденные константы, включая возможные ключи ресурсов, могут попасть в контекст модели; запускайте такое исследование только для данных, которые разрешаете передавать провайдеру.

Пользовательские проекты не публикуются вместе с приложением. Перед отправкой отчёта в GitHub Issues проверьте, что в нём нет личных файлов, ключей, токенов, сертификатов и конфиденциальных фрагментов кода.

Android ADB используется только для выбранных вручную действий. Импорт копирует APK/сплиты, а не приватные данные приложения. Команда установки требует явного выбора файлов; замена существующей установки включается отдельным переключателем. ИИ не имеет доступа к подписи или устройствам.

Сертификаты и keystore выбираются пользователем. Пароли передаются локальным инструментам и не сохраняются в проекте или рецепте. Для bundletool и osslsigncode применяются анонимные временные файловые дескрипторы: именованные файлы с паролями не остаются после остановки. Список Apple identities читается только по нажатию кнопки.

Вход ChatGPT выполняется официальным Codex app-server через браузер. Для AnyPatcher используется отдельный каталог клиента и отдельные записи защищённого системного хранилища; чужие сессии Codex/ChatGPT не читаются. Локальная история диалогов и аналитика Codex отключены, исследования создают временные потоки. Служебные локальные файлы Codex находятся рядом с каталогом проектов; правила обработки данных аккаунта у OpenAI действуют отдельно. Каталог моделей запрашивается после входа при разрешённом облачном режиме.


Начиная с 0.2.6 локальный файл `research-memory.json` внутри проекта сохраняет ограниченный журнал исследования: очищенные фрагменты результатов инструментов, адреса, выборки и заметки. Он может содержать данные анализируемого приложения. При следующем облачном запросе компактный указатель и запрошенные доказательства отправляются выбранному провайдеру с тем же подтверждением облачного доступа. Ключи подтверждённого AES-кодека сохраняются отдельно в Связке ключей. Для удаления журнала закройте приложение и удалите только `research-memory.json`; проект и его файлы останутся.
