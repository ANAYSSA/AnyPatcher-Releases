# Данные в AnyPatcher 0.1

Файлы, исходные копии, изменения и журнал проекта хранятся на вашем Mac. Для обычного анализа и редактирования приложение не отправляет их разработчику и не требует аккаунта AnyPatcher. В версии 0.1 нет встроенной аналитики использования или автоматической отправки crash-отчётов.

Локальный помощник обращается к Ollama на этом Mac. Для этого модель должна быть заранее загружена. Скачивание Ollama, моделей, внешних анализаторов и обновлений выполняется отдельно.

При включении облачного ИИ приложение передаёт выбранному провайдеру текст задания и фрагменты активного проекта, которые помощник читает через ограниченные инструменты. Для каждого облачного запуска требуется согласие. Полный архив автоматически не загружается. Автоматическое скрытие распространённых секретов не заменяет вашу проверку содержимого.

API-ключи хранятся в macOS Keychain. Они не включаются в рецепты, проекты и экспорт контекста. Ключи и IV для ручного декодирования ресурсов остаются в памяти формы и не сохраняются как настройки.

Пользовательские проекты не публикуются вместе с приложением. Перед отправкой отчёта в GitHub Issues проверьте, что в нём нет личных файлов, ключей, токенов, сертификатов и конфиденциальных фрагментов кода.
