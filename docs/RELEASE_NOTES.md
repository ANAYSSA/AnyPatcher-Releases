# AnyPatcher 0.2.5 — Dzip, IL2CPP и исследование ресурсов

- `files.dz` / Marmalade DTRZ: список вложений, поиск, чтение Derbh, редактор текста и проверяемая замена одного ресурса с сохранением остальных блоков. Dzip CLI входит в DMG.
- Ассемблер и псевдокод: навигация по функциям, строкам, ссылкам и методам IL2CPP с переходом к конкретному адресу.
- Помощник проверяет сохранённое декодирование перед новым исследованием. Добавлены инструменты для методов IL2CPP, статических полей и анализа вызывающих функций.
- Поиск больше не пропускает бинарники крупнее 16 МиБ. Ограничения охвата и продолжение показаны явно.
- Сокращение ответов инструментов сохраняет адреса, предупреждения и навигацию; повторные одинаковые вызовы не читают данные заново. Статистика токенов отображается компактно.

Проверено чтение `moves.xml` из Dzip, изменение отдельной копии с сохранением остальных 119 вложений и отмена. На отдельном IPA параметры расшифровки найдены через код загрузчика, XML проверен и обратное кодирование совпало с исходником. Эти проверки не гарантируют поддержку любого приложения или качество ответа каждой модели.

**Apple Silicon, macOS 13+.** Preview подписан ad-hoc, без нотарификации Apple. Для псевдокода нужны отдельно установленные Ghidra и JDK. Проекты, вход и сохранённые способы декодирования сохраняются при обновлении.

Dzip CLI — отдельный компонент AGPL-3.0-or-later. Полный архив его исходников с зависимостями и инструкцией автономной сборки приложен к релизу и находится внутри приложения в `Contents/Resources/notices/dzip`. Исходники самого AnyPatcher остаются закрытыми.
