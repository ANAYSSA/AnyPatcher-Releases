# AnyPatcher 0.2.6 — исследование без повторов и новые XML-блоки

- Добавление, вставка, клонирование, замена и удаление XML-узлов; пакет связанных изменений создаёт один план для просмотра. Поддержаны обычные файлы, декодированные ресурсы Unity и XML внутри Dzip. Текстовые вставки используют однозначный якорь.
- Структурное чтение XML: выбор узлов, компактный обзор, поиск внутри выбранных элементов. Большой документ не нужно целиком отправлять модели.
- Локальный журнал результатов и заметок исследования сохраняется между запросами и запусками. При изменении файлов старые результаты исключаются. Подтверждённые способы расшифровки сохраняются; параметры AES — в Связке ключей.
- Поиск загрузчика IL2CPP объединяет сведения о вызывающих функциях Base64 и дешифраторов в один компактный список. Связь с ресурсом и параметры по-прежнему требуют проверки; универсальная расшифровка не обещается.
- Экономный режим включён по умолчанию: 16 вызовов, резерв на проверку и план. Расширенный режим — 24 вызова. Это ограничения исследования, а не гарантированный процент расхода подписки.

Проверено добавление блока в синтетический зашифрованный XML размером 2,2 МБ, сохранность остальных данных, обратное кодирование и отмена. Проверки ИИ использовали имитацию ответов провайдера и не расходовали облачный лимит; успешный автономный поиск в каждом приложении не гарантируется.

**Apple Silicon, macOS 13+.** Preview подписан ad-hoc, без нотарификации Apple. Проекты и настройки сохраняются при обновлении.

Dzip CLI — отдельный компонент AGPL-3.0-or-later. Архив его исходников с зависимостями приложен к релизу и включён в приложение. Исходники AnyPatcher остаются закрытыми.
