# AnyPatcher

Локальная мастерская для исследования и изменения приложений на macOS.
Откройте IPA, APK, EXE или отдельный ресурс, найдите нужные данные, проверьте патч и экспортируйте отдельную копию.

**[Скачать macOS DMG](https://github.com/ANAYSSA/AnyPatcher-Releases/releases) · [Инструкция на русском](docs/GUIDE_RU.md) · [Инструменты и ИИ](docs/INTEGRATIONS.md)**

Простой режим показывает файлы, ресурсы, поиск и понятный порядок действий. Экспертный режим добавляет HEX, дизассемблирование, секции, импорты и функции. Оригинал сохраняется отдельно; изменения можно отменять и переносить рецептами с проверкой SHA-256.

## Возможности версии 0.1

| Возможность | Что действительно делает |
|---|---|
| IPA / APK / ZIP | Проверяет архив, создаёт проект, позволяет читать и изменять содержимое, собирает отдельную копию |
| EXE / DLL / Mach-O / ELF | Показывает секции, импорты, экспорты и функции через LIEF; инструкции через Capstone |
| Файлы | Поиск, просмотр изображений, редактирование UTF-8, JSON, XML и plist; HEX с проверкой старых байт |
| Unity | Перечень объектов, просмотр TextAsset, Texture2D и Sprite; изменение TextAsset с проверкой остальных объектов |
| Кодеки ресурсов | Plain, Base64, gzip, zlib, AES-CBC + Base64 с указанными пользователем ключом и IV |
| История | Предварительный план, применение, отмена, повтор, сохранение и воспроизведение рецепта |
| Диагностика | Проверки проекта, контрольные суммы, эвристики защиты, заметки, импорт текстового журнала, экспорт контекста |
| Декомпиляция | Адаптеры установленных отдельно Ghidra и JADX |
| ИИ | Необязательные Ollama, OpenAI Responses, Anthropic Messages и Gemini; предложения патчей требуют ручного применения |

Базовые анализаторы и Python встроены в DMG. Ручные функции работают без аккаунта и интернета. Для локального ИИ нужно заранее установить Ollama и загрузить подходящую модель. Облачные API используют собственные ключи пользователя, хранящиеся в macOS Keychain.

## Границы

Это ранняя рабочая версия, а не универсальный автоматический взломщик. Зашифрованный код IPA не расшифровывается без доступного открытого экземпляра. Серверные функции не становятся локальными от изменения файла. Декомпилированный код не равен исходному проекту.

Экспорт IPA и APK **требует новой подписи**. В версии 0.1 нет автоматической цепочки Apktool/smali → zipalign → apksigner, сборки iOS-приложения из декомпилированного кода, редактора Unity-анимаций или автоматического восстановления IL2CPP. Ghidra/JADX подключаются отдельно. Статус «проверено» относится к структуре и контрольным суммам, а не к запуску изменённого приложения.

DMG выпускается для Apple Silicon и Intel. Приложение имеет локальную ad-hoc подпись и **не нотарифицировано Apple**. Windows-версия самого AnyPatcher пока не выпускается; EXE можно исследовать на Mac.
