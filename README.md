# AnyPatcher

Локальная мастерская для исследования и изменения приложений на macOS.
Откройте IPA, APK, EXE или отдельный ресурс, найдите нужные данные, проверьте патч и экспортируйте отдельную копию.

**[Скачать macOS DMG](https://github.com/ANAYSSA/AnyPatcher-Releases/releases) · [Инструкция на русском](docs/GUIDE_RU.md) · [Инструменты и ИИ](docs/INTEGRATIONS.md)**

Простой режим показывает паспорт приложения, ресурсы и код. Исполняемые файлы открываются с ассемблером, функциями и переходом к псевдокоду; HEX доступен отдельно в экспертном режиме. Оригинал сохраняется, изменения можно отменять и переносить рецептами с проверкой SHA-256.

## Возможности версии 0.2

| Возможность | Что делает |
|---|---|
| Паспорт проекта | Определяет пакет, основной бинарник, архитектуры и технологии по содержимому; разделяет код, ресурсы и настройки |
| Mach-O / ELF / PE | Секции, импорты, функции; автоматический выбор начала кода; ассемблер Capstone и псевдокод через Ghidra |
| Unity | Вкладка только для распознанных контейнеров; поиск по всем объектам, TextAsset/изображения, редактирование текста и сохранение состояния просмотра |
| Файлы и история | Поиск, UTF-8/JSON/XML/plist, замена и извлечение ресурсов, планы с проверкой, отмена/повтор и рецепты |
| APK-мастерская | Apktool: Manifest, ресурсы и Smali; отдельная история правок; сборка → zipalign → apksigner → проверка подписи |
| Android-комплекты | Просмотр XAPK/APKM/APKS, открытие отдельных APK, зависимости сплитов; AAB → подписанный APKS через bundletool |
| Android-устройство | По явному нажатию: ADB-импорт установленных APK/сплитов, установка выбранного набора, запуск и журнал |
| Подписи | Android keystore; экспериментальная переподпись IPA с существующими сертификатом и профилями; Authenticode PE через PFX |
| ИИ | Боковой помощник: локальная Ollama или облачные OpenAI/Anthropic/Gemini; чтение проекта и предложения проверяемых патчей |
| Декомпиляция Android | JADX для просмотра Java из DEX/APK; изменения в APK-мастерской вносятся в Smali/ресурсы |

Python, LIEF, Capstone и UnityPy входят в DMG. Для псевдокода и сборки **нужно отдельно установить Ghidra/JADX, JDK, Apktool и Android SDK Build Tools**, затем указать пути в «Инструментах». Ollama и модели тоже устанавливаются отдельно. Обычный анализ не требует аккаунта или интернета. [Настройка инструментов](docs/INTEGRATIONS.md) · [Сборка и подписи](docs/BUILDS.md).

## Границы

Это preview-версия. Зашифрованный код IPA не расшифровывается автоматически. Псевдокод не восстанавливает исходный проект; сведения о типах и именах могут отсутствовать. Редактор Unity-анимаций, восстановление IL2CPP, универсальное клонирование приложений и генератор mod menu пока не реализованы.

IPA требует действительного сертификата с закрытым ключом и подходящих provisioning profiles; переподпись экспериментальная и не создаёт аккаунт Apple или профили. Проверенная подпись не подтверждает работоспособность приложения на устройстве. APK-подписи после изменений заменяются выбранным ключом; обновление поверх оригинала с другим ключом может быть невозможно.

Начиная с 0.2.4 DMG выпускается только для Apple Silicon (M1 и новее), macOS 13+. Приложение имеет ad-hoc подпись и **не нотарифицировано Apple**. Windows-версия самого AnyPatcher пока не выпускается; EXE можно исследовать на Mac.
